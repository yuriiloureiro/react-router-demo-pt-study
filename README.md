# Emoji Critic — React Router Demo

Uma aplicação de estudo para praticar roteamento com React Router v6. Neste projeto você encontrará exemplos de:

- Roteamento básico com Routes / Route
- Navegação com Link e NavLink
- Rotas aninhadas (Outlet)
- Rotas dinâmicas (useParams)
- Navegação programática (useNavigate)
- Página 404 (rota curinga)

Este repositório é o resultado das aulas/práticas do Bootcamp TripleTen — Sprint focado em React Router.

## Requisitos

- Node.js >= 18 (recomendado)
- npm >= 9 (ou yarn)
- Git (para versionamento e push ao GitHub)
